    - Role-based automatic redirect (Admin -> /dashboard, Staff -> /staff, Customer -> /portal)

    - Safe neutral confirmation message

    - Token extraction from URL with live password checklist validation
[x] Route Guards & Access Control
    - RequireAdmin and RequireRole components protecting internal workflows
[x] Role Switcher & Account Overview (/account)
    - One-click testing switcher between Admin, Staff, and Customer workspaces
[x] Admin Staff Management (/settings/staff, /admin/staff)
    - Admin-only staff account creation with name, email, and temporary password
    - Staff directory listing with Active / Inactive status toggle

[CATALOG & CONFIGURATION]
[x] Products Management (/products, /settings/products)
    - Product list with search and product type filtering
    - Create/edit drawer (name, type, sales price, cost price, description/notes)
    - Live profit and gross margin calculation
    - Admin edit access, Staff view-only mode (/staff catalog tab)
[x] Product Variants Editor
    - Dynamic attribute/value configuration (e.g., Brand -> Odoo)
    - Price adjustments (e.g., Odoo Brand +₹560 extra price)
    - Live effective price calculation (Base Price + Variant Extra)
[x] Subscription Plans (/plans, /settings/plans)
    - Create and edit subscription plans (name, base price, billing interval)
    - Billing intervals: Daily, Weekly, Monthly, Yearly
    - Minimum quantity validation
    - Availability validity window (availableFrom and availableTo dates)
    - Availability state computation (Active, Upcoming, Expired)
    - Four behavioral control switches:
      1. Closes automatically when it ends
      2. Can be closed early
      3. Can be paused
      4. Can be renewed
[x] Automated Taxes Management (/taxes, /settings/taxes)
    - Create and edit automated tax rules (name, percentage rate, application scope)
    - Scope configuration: All Products, Product Type, or Specific Product
    - Automated tax computation and line item integration in invoices
[x] Discounts Management System (/settings/discounts, /admin/discounts)
    - Admin discount rule configuration interface (Fixed Amount or Percentage)
    - Minimum purchase amount, minimum quantity, usage limits (used_count / usage_limit)
    - Validity start and end dates with computed status badges: Scheduled, Active, Expired, Used Up
    - Applicability scope: Specific Products or Whole Subscription
    - Automated discount line appearance on subscriptions and generated invoices
[x] Quotation Templates (/templates)
    - Admin/Staff quotation template builder with validity days, plan, terms, product lines
    - "Create Quotation from Template" action prefilling new subscription form

[CUSTOMER PORTAL & BILLING]
[x] Customer Plan Selection & Checkout (/billing, /portal/billing, /checkout)
    - Visual plan selection with billing period indicators
    - Add-on variant selection with live total updates
    - Real-time tax computation and order summary preview
    - Checkout confirmation creating active customer subscription and first invoice
[x] Customer Self-Service Portal (/portal)
    - Overview tab: Active subscriptions count, next invoice date, outstanding balance
    - My Subscriptions: View plan details, status badges, renewal dates
    - Self-service subscription controls (Pause, Resume, Renew, Close) strictly
      constrained by plan behavior switches
    - My Invoices: View invoices, status badges, payment instructions, printable invoice view
    - Pay Now flow modal for outstanding invoices

[OPERATIONS, SUBSCRIPTIONS & INVOICES]
[x] Internal Subscription Management (/staff, /admin, tab=subscriptions)
    - Status tabs with real-time counts: All, Draft, Quotation, Confirmed, Active, Closed
    - StatusStepper visual component displaying lifecycle progression and completed dates
    - Action buttons strictly constrained by subscription status and plan flags:
      * Draft: Edit, Send Quotation, Discard
      * Quotation: Confirm, Edit, Discard
      * Confirmed: Activate
      * Active: Pause, Resume, Renew, Close
      * Closed: Read-only audit state
    - Create subscription drawer with searchable customer, plan, and product lines
    - Detail drawer with full audit history timeline and linked invoices
[x] Invoice Management (/invoices, tab=invoices)
    - Status tabs with real-time counts: All, Draft, Outstanding (confirmed), Paid, Overdue
    - Lifecycle transitions: Draft -> Confirmed -> Paid (or Cancelled)
    - Actions: Confirm invoice, Send invoice, Print/PDF invoice, Cancel invoice
    - Overdue tracking with dynamic day calculation (e.g., "X days overdue")
    - Printable layout with company branding and tax breakdown
[x] Automated Recurring Billing Runs (/billing-runs)
    - "Run Billing" execution trigger with confirmation dialog
    - Automatic invoice generation for subscriptions due on or before today
    - Duplicate billing prevention with detailed run statistics:
      * Invoices Created
      * Subscriptions Skipped (already billed for current period)
      * Failed runs
    - Historical billing run audit log table
[x] Payments Management (/payments, tab=payments)
    - Record payment modal from invoice detail or payments tab
    - Payment methods supported: Bank Wire / NEFT, UPI / Instant Transfer,
      Credit Card (POS), Corporate Cheque, Cash / Direct Deposit
    - Automatic invoice status transition to Paid when fully settled
    - Filterable payments history by method, date range, and customer

[BACKEND & DATABASE INFRASTRUCTURE]
[x] Express API routes & controllers for Commercial, Plans, Products, Variants, Users
[x] PostgreSQL database migration (001_quotation_subscription_management.sql)
